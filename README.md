# Exoteric-NILM
Some bits and bobs to share with the Exoteric team corresponding to the NILM challenge.

This repo contains the dataset parsers for the PLAID (https://figshare.com/articles/dataset/PLAID_-_A_Voltage_and_Current_Measurement_Dataset_for_Plug_Load_Appliance_Identification_in_Households/10084619) and WHITED (https://www.cs.cit.tum.de/dis/resources/whited/) datasets alongside augmentation functions (stretching/shrinking, scaling and shifting).

It also includes a way of setting up a test run for both training and testing of a potential ML model/method. This framework will be updated and upgraded soon!
